## Introduction

`create-nest-starter` generates a new NestJS project for you. Run it, answer a
couple of prompts, and you get a working application you can build on top of.

The generated project ships with:

- Express + REST API with Redis-backed sessions
- No-op defaults for persistence, so it boots without a database
- Global rate limiting and Swagger docs
