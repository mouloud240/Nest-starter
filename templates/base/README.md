# NestJS Starter Base

This is the base project generated by `create-nestforge`. It is an Express + REST + Redis-session NestJS app with no-op defaults so it can boot without a database or external services.

## Prerequisites

- Node.js 20+
- pnpm
- Redis (local or Docker): `docker run -p 6379:6379 redis:latest`

## Setup

```bash
pnpm install
cp .env.example .env
# edit .env with your Redis settings
pnpm start:dev
```

## Scripts

| Script | Description |
| ------ | ----------- |
| `pnpm start:dev` | Run in development mode |
| `pnpm build` | Build the application |
| `pnpm test` | Run unit tests |
| `pnpm lint` | Lint the codebase |
| `pnpm format` | Format with Prettier |

## Notes

- `USER_REPOSITORY` is a no-op stub. Add a real repository when you are ready to persist users.
- OAuth endpoints exist but are not fully wired. Configure the providers in `.env` and implement the strategy callbacks before use.
- Rate limiting is enabled globally via `ThrottlerGuard`.
