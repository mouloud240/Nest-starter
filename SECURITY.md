# Security Policy

## Supported versions

Only the latest published version of `create-nestforge` is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately by emailing **mouloudhasrane24@gmail.com** instead of opening a public issue.

Please include:

- A clear description of the vulnerability.
- Steps to reproduce, if possible.
- The affected version(s).

We will respond as soon as possible and coordinate a fix and disclosure.
